# docs/assets

Diagrams and images referenced from `docs/`: topology diagrams, trust-zone
figures, sequence diagrams, wiring photos.

- Prefer formats that can be diffed (SVG, or Mermaid inside the Markdown
  itself) over PNG.
- Commit the editable source (e.g. `.drawio`, `.excalidraw`) alongside any
  exported image.
- Keep files small. This is a code repository, not a photo archive.

## Current owner (provisional)

Shared. Anyone may add diagrams. The project lead reviews.
